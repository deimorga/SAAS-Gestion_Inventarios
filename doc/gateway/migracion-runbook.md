# Runbook de migración a Traefik — movido a `micronuba-infra`

Este documento era el procedimiento para pasar el servidor compartido del gateway anterior a
Traefik. La migración se completó en 2026 y el runbook trataba sobre todo de otros proyectos
(rutas, contenedores y certificados de cada uno).

El histórico vive en el repositorio **privado** `micronuba-infra`. Se retiró de aquí el
2026-10-27 porque este repositorio es público. Ver
[`ci-diagnostico-y-estrategia.md`](../Arquitectura/ci-diagnostico-y-estrategia.md).

Cómo se conecta Inventarios a Traefik hoy: [`ambientes-produccion-staging.md`](ambientes-produccion-staging.md).
